# Security policy

Open Browser Index contains public factual data and build scripts. It does not
handle credentials, user accounts, or a production service.

Please do not put secrets or private URLs in issues or pull requests. For a
repository or CI vulnerability, use GitHub's private vulnerability reporting
for this repository. Include the affected revision or file, reproduction
steps, impact, and a suggested mitigation where possible. Maintainers will
acknowledge reports when practical and coordinate disclosure with the reporter.

Factual inaccuracies are not security vulnerabilities; use the factual
correction issue form for those.
