# Code of Conduct

## Our standard

Participants in Open Browser Index must be respectful, factual, and open to
correction. Harassment, discrimination, intimidation, doxxing, threats,
sexualized conduct, and personal attacks are not acceptable. Do not manipulate
evidence, misrepresent a source, or use this project to promote a vendor.

## Enforcement

Project maintainers may edit, close, or remove contributions and may ban
participants for conduct that violates this code. Reports should be sent to
the maintainers through the repository's private contact mechanism or a GitHub
security/private report when appropriate. Include links, dates, and context;
do not publish sensitive information in an issue. Reports will be handled as
confidentially as practical.

This code is adapted from the Contributor Covenant spirit and applies to
issues, pull requests, reviews, discussions, and project spaces.
